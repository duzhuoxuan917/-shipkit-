# Selling ShipKit

## Positioning

Do not sell ShipKit as another semantic-versioning tool. Release Please and semantic-release already cover the basic automation for free. Sell the reduction in release coordination work:

> ShipKit gives small software teams a reviewed release plan, a predictable approval step, and one command to publish the result.

## First offer

Sell a fixed-price setup service before building a hosted product:

- `RMB 2,000-5,000`: configure one repository
- `RMB 5,000-12,000`: configure a monorepo and package publishing
- `RMB 12,000+`: add internal approvals, notifications, and migration support

The service creates real customer conversations and tells you which Pro features deserve implementation.

## Product listing copy

**ShipKit Pro: release automation for small engineering teams**

Stop rebuilding release checklists in every repository. ShipKit Pro coordinates versioning, changelogs, approvals, package publishing, and team notifications in one reviewable workflow. The open-source Community edition remains free; Pro adds the team features that save time every release.

## Distribution

- GitHub repository and Releases for trust
- GitHub Discussions for questions and feature discovery
- Short demo videos showing a release from merged PR to published artifact
- Direct outreach to small agencies and teams maintaining npm/Docker packages
- A checkout page linked from the README once payment is configured
