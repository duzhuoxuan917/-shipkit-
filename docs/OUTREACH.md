# Outreach

## Who to contact

Look for small teams maintaining npm packages, Docker images, Python packages, or several GitHub repositories. The strongest signal is a public repository with a manual release checklist, frequent releases, or multiple packages.

## Message

```text
你好，我在做 GitHub 发布流程自动化配置服务。

可以帮你把版本号、Changelog、CI 检查和 GitHub Release
整理成一套自动流程，通常 1-2 天完成。

单仓库配置费用 RMB 2,999，包含配置、文档、一次真实发布和 7 天维护。
我可以先免费帮你看一下现有发布流程。
```

## Qualification questions

- How many repositories or packages do you release?
- Which release step is still manual?
- Do you publish to npm, Docker, PyPI, or another registry?
- Who needs to approve a release?
- What would a successful release process save or prevent?

Do not send unsolicited messages in bulk. Contact people where a relevant public problem is visible, personalize the message, and stop when they decline.
