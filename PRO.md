# ShipKit Pro

ShipKit Community is the open-source release core. Pro is for teams that need to coordinate releases across packages, registries, and people.

## What customers buy

- Monorepo release plans with dependent package detection
- npm, Docker, and PyPI publishing targets
- Approval gates before a tag is created
- Slack and Feishu notifications
- Release audit history
- Private support and commercial licensing

## Suggested offer

| Plan | Price | Best for |
| --- | ---: | --- |
| Community | Free | Individual repositories |
| Pro | $49 one-time | Solo developers and small teams |
| Team | $19/month | Teams with multiple repositories |
| Setup service | $299+ | Teams that want migration and configuration done for them |

## How to launch

1. Add a real checkout URL to the README and GitHub repository description.
2. Deliver Pro as a private npm package or signed binary.
3. Keep the Community CLI useful and never hide its existing functionality behind a license key.
4. Ask every early buyer for one concrete workflow that is still manual.

This file is a product boundary, not a license key implementation. Payment, tax, and customer delivery still need to be connected to the seller's chosen checkout provider.
